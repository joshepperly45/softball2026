# softball2026

A hostable softball roster and scorekeeping site built as a lightweight static web app.

## Features

- Save a reusable roster with names, gender, and preferred positions
- Build a daily lineup from the saved roster with configurable lineup rules
- Track a game batter by batter with softball/baseball scoring shortcuts
- Record substitutions during the game
- Review saved player stats such as AVG, OBP, SLG, OPS, RBI, and runs scored

## Running locally

Open the site with any static web server, for example:

```bash
python3 -m http.server 4173
```

Then browse to `http://localhost:4173`.

## Tests
